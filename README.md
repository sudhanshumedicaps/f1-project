# 🏎️ F1 Racing Analytics

An interactive Formula 1 data visualization project built using **Tableau, Python, and Flask**.

### Features
- Driver and constructor performance analysis
- Race wins and championship statistics
- Tyre and circuit analysis
- Lap time visualizations
- Interactive Tableau dashboard

### Tech Stack
Python, Flask, Tableau, HTML, CSS, Vercel
